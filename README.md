Opis:
Najjaśniejsze forum dla ludzi lubiących decydować o swoim ID oraz nie przepadających za najsłodszymi stworzeniami internetu

Instalacja i uruchomienie:

1. Wykonanie komendy npm install w konsoli

2. Uruchomienie dockera (plik docker.txt)

3. Uruchomienie aplikacji npm start

Funkcjonalności:
Program pozwala na dodawanie nowych użytkowników, tworzenie nowych wątków oraz przypisywanie użytkowników do tych wątków

Technologie
Program wykorzystuje EJS, MongoDB oraz dockera
